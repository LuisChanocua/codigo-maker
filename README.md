# 🧩 Generador de Códigos Únicos | Código Maker

Una herramienta web para generar códigos únicos personalizados según las reglas que definas. Ideal para sorteos, validaciones, promociones, campañas de marketing o desarrollo de productos.

## 🔧 Características

- Definición de longitud total del código
- Personalización de:
  - Letras permitidas y cantidad
  - Números permitidos y cantidad
  - Caracteres especiales (opcionales) y cantidad
  - Uso combinado de mayúsculas y minúsculas
- Cálculo automático de combinaciones posibles
- Vista previa en tiempo real de un código generado
- Generación masiva con opción de exportar a archivo `.txt`
- Detección y exportación de códigos duplicados
- Diseño responsivo con estilo moderno

## 🚀 Cómo usar

1. Abre el archivo `index.html` en tu navegador.
2. Completa los campos del formulario según tus necesidades.
3. Presiona **"Generar Códigos"** para ver una vista previa.
4. Presiona **"Exportar a TXT"** para descargar los códigos generados.
